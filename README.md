### 🥇 [Dataman: Multi-Agent Automated Data Analysis System](https://github.com/ZewenLu1008/Dataman)

An autonomous, production-ready data preparation system built with LangGraph. It transforms raw, heterogeneous data sources into analysis-ready datasets using a sophisticated multi-agent architecture (Profiler, Coder, Executor, QA, EDA) with self-healing execution loops.
**Tech:** `LangGraph` `Multi-Agent System` `LLMs` `Pandas` `OCR`

### 👁️ [Nutrition Prediction](https://github.com/ZewenLu1008/nutrition-prediction)

A dual-branch CNN architecture initialized from scratch to estimate caloric content ($$R^2 \approx 0.81$$) from RGB and depth images. Emphasizes architectural reasoning and feature fusion over transfer learning.
**Tech:** `PyTorch` `Computer Vision` `Torchvision`

### 📝 [Domain-Aware Text Classifier](https://github.com/ZewenLu1008/domain-aware-text-classifier)

A Kaggle competition project achieving 96% accuracy in distinguishing machine-generated text from human writing. Utilizes a two-stage domain adaptation strategy and TF-IDF feature extraction.
**Tech:** `Scikit-learn` `NLP` `TF-IDF` `Logistic Regression`

### 📊 [Road Accident Analysis](https://github.com/ZewenLu1008/road-accident-analysis)

End-to-end statistical analysis and machine learning project using real-world Victorian official records to investigate road safety factors and predict injury severity.
**Tech:** `Pandas` `SciPy` `Decision Trees` `KNN`
